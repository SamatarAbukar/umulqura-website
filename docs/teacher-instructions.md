# Taking the register — instructions for teachers

Give this to teaching staff. Send the password separately, never in the same message.

---

## The first time (once per phone)

1. Open **umulquralc.com/attendance.html**

   This page is deliberately **not** in the website menu. Type the address, or use the link the
   office sends you.

2. Save it so you don't have to type it again:
   - **iPhone / Safari:** Share → *Add to Home Screen*
   - **Android / Chrome:** ⋮ → *Add to Home screen*
   - **Laptop:** bookmark it

3. Get the **staff password** from the office. All teachers share the same one.

## Every class

1. Open the page and enter the staff password → **Sign In**.
   You stay signed in until you close the browser.
2. Choose **your name** from the Teacher list.
3. Choose the **class type**. If it's the Weekend Class, also choose **Morning** or **Afternoon**.
4. Check the **date**. It fills in today automatically — change it only if you're recording an
   earlier class.
5. For each student, tap **Present** or **Absent**, then tick **Lesson** and **Review** if they
   passed. Absent students' ticks grey out on their own — that's normal.
6. Tap **Save Attendance** and wait for **"Saved N students for …"**.

If you don't see that confirmation, it hasn't saved.

## Adding and removing students

**Add Student** — first name, last name, date of birth (optional) → *Add to Class*. They stay on
that class list for every future lesson, so you only add someone once.

**Remove** — takes a student off the class list from now on. Their past attendance is kept, so
removing someone never erases their record.

## If you make a mistake

Fix it and press **Save Attendance** again.

Saving the same class and the same date twice **replaces** that day's entry — it never creates a
duplicate. Correcting a mistake later in the day is always safe.

## If something goes wrong

| What you see | What to do |
| --- | --- |
| "Incorrect password." | Check for capital letters or a trailing space. Ask the office. |
| Nothing loads, or an error message | Check your internet connection and try again. The page needs to be online. |
| The wrong students are listed | Check the class type, and Morning vs Afternoon. |
| "You have unsaved attendance…" | You have ticks that aren't saved. Cancel and press Save first, or continue to discard them. |

## Please

Don't share the page or the password with anyone outside the teaching staff — it holds students'
names and dates of birth.
